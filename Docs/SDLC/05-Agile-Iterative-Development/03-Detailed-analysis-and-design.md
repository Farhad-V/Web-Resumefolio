# Detailed Analysis & Design

Start with the selected issue and acceptance criteria. Clarify actors, business rules, states and failure paths that affect the slice. Refine the necessary screen flow, data changes, component behavior or API contract using the [System Design Guide](../System-design-guide.md).

Record the decisions in the owning requirements or design document and link them from the issue. Identify the main and failure-path checks before starting [Implementation](04-Implementation.md) and [Testing](05-Testing.md).
