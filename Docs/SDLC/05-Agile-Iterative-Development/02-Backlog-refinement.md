# Backlog Refinement

Refine upcoming work on the [GitHub board](https://github.com/users/Farhad-V/projects/7/views/1) as questions or feedback arise. Give each selected item a clear outcome, linked requirement, observable acceptance checks and any dependency or unresolved question. Split items that cover several outcomes into smaller pieces that can each be reviewed.

Update the owning issue. Bring clarified items into [Sprint Planning](01-Sprint-planning.md) and feed new items or changed priorities back from the [Sprint Review](06-Sprint-review.md).
