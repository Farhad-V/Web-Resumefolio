# 2. Design Goals And Principles

[UI/UX Design index](02-UI-UX-Design.md)

## UX Goals
Make it easy to tailor professional materials, preview what will be shared and distinguish a draft from material already published or submitted.

## Design Principles
Use consistent language, a clear primary action and visible feedback. Separate draft apply, publication and file sharing into distinct actions.

## Constraints
Design for browser-based React and Inertia screens and server-authorized actions. Visual branding and polished styles remain open.
