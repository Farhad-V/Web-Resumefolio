# 3. System Context

[High-Level Design index](01-High-Level-Design.md)

### 3.1 Actors / Users
Invited users maintain their materials. Employers receive limited share access. Repository collaborators act within assigned grants. Administrators manage accounts and operational metadata.

### 3.2 External Systems
System mail supports invitations and recovery. Standard Git clients interact with ProjectForge through controlled native Git transport. Personal provider integrations are outside the MVP.
