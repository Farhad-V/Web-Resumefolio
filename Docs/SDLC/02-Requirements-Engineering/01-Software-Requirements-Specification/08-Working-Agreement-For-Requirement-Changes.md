# Working agreement for requirement changes

Retain each stable requirement ID and record the exact actor, precondition, allowed outcome and observable denial or failure behavior. When a change is proposed, update the scope disposition and acceptance conditions after review. Link the resulting work in the [backlog](../02-Product-Backlog/README.md) and update the [RTM](../03-Requirements-Traceability-Matrix/README.md) for affected design and checks.
