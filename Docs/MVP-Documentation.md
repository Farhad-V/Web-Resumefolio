# MVP Documentation

Resumefolio helps invited users turn a reusable profile into tailored resumes, share selected materials privately and track job applications. A separate system, ProjectForge, provides real Git repositories, issues and a simple Kanban board.

**Status:** The MVP scope and technical baseline are selected. Implementation and product testing have yet to start. The next step is [isolated project setup](https://github.com/Farhad-V/Web-Resumefolio/issues/37) after the host and design prerequisites are reviewed.
