# Web Resumefolio

Resumefolio is a private workspace for profiles, tailored resumes/portfolios, cover letters and manual job applications. The current product scope is the MVP; implementation has not started.

- Core: invited accounts, dashboard, explicit resume updates/publication, private same-server media, PDFs/protected employer sharing and preserved actual submitted materials.
- ProjectForge: a separate user-scoped API system with real Git transfers/permissions/file-history, issues and simple Kanban.
- After MVP: private mail/calendar, AI, advanced review/releases, general Sprints and user workflow/deployment execution.
